# Placement Predictor: setup and machine-learning notes

## Start the website and backend

Install Python, then open a terminal in this project folder:

```powershell
cd backend
pip install -r requirements.txt
python app.py
```

Keep the backend terminal open and open `placement_predictor.html` in a browser. The profile tools work in browser-only mode; model predictions, account storage, application syncing, and peer summaries need the Flask backend.

## Train the model again

With the Flask backend running locally, open the website's **ML Lab** tab and click **Train model now** to run the same pipeline from the page. The live log shows the CSV size and each classifier as it is tuned. This button uses only the CSV; dashboard profiles are not silently added to training data. It is restricted to requests from the local computer.

You can also train from a terminal. From the project folder:

```powershell
cd ml
python train_model.py placement_data.csv
```

The script cleans the CSV, makes a stratified 80/20 train/test split, tunes four classifiers with 5-fold cross-validation on the training split, evaluates the selected model on the held-out test split, writes charts and metrics, and saves the model to `ml/output/`. The backend serves the saved model. If it cannot load the model file, it attempts to retrain from the shipped CSV.

## Be clear about the data

The included `ml/placement_data.csv` contains 1,500 **synthetic** student records generated by `ml/data/generate_dataset.py`. Its metrics show how well candidate algorithms fit the generated data. They do not measure real-world placement accuracy and must not be presented as results for your college or as a hiring probability.

For a meaningful evaluation, use placement records approved for this project by your college. Keep personal identifiers out of the dataset. The training script accepts a CSV with a binary `placed` column and supported profile features (such as `cgpa`, `aptitude`, `programming`, `projects`, `internships`, `backlogs`); an optional `salary` column enables salary regression. It also detects the public Kaggle Campus Recruitment format. Retrain after replacing the CSV. Preserve the `.meta.json` source note unless you know what it describes.

## What the site shows

The Dashboard's readiness score is a transparent rule-based practice estimate. ML Lab shows the separately trained classifier's dataset source, train/test metrics, comparison, and charts. Neither score is a promise of a job outcome. Check eligibility and dates with your own placement cell because each college and hiring cycle differs.
